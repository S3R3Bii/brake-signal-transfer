# Deceleration estimation across road environments

**Study in progress.** The fixed protocol and public-data ingestion are implemented; no performance claim is made until selection, held-out-road scoring and independent checks finish.

The decision is whether causal speed-based acceleration estimates and a low-false-alert operating point survive a change of road environment. This uses historical NGSIM reference signals, not independently measured brake actuation. It demonstrates SQL lineage, grouped evaluation, baseline comparisons and a traceable model-selection process.

See [the protocol](PROTOCOL.md), [source and reuse terms](SOURCES.md) and [model-validation requirements](MODEL_VALIDATION_STANDARD.md). Manuscripts are private. No private vehicle information or video is included.
